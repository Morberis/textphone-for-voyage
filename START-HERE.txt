TextPhone for Voyage 0.7.0

INSTALL AS A MOD
1. Preserve a complete world export and use a test copy.
2. Voyage Creator Studio > Mods > Create Mod. Name it, then Save mod.
3. Open build/generic-phone-voyage-mod.json and copy all of it.
4. In that MOD's Content root JSON editor, replace all text and Save mod.
5. Reload; in your WORLD's Mods page choose Add draft for it, then Apply.
6. Reload and check the world; start a fresh test game.

Creator-Guide.pdf has detailed installation, custom apps, API, upgrade and rollback steps.
The HTML installer is a local fallback for edited worlds and instruction conflicts.
The native mod JSON must not replace a populated WORLD's Content root.

PLAYER WORKFLOW
Open Workshop in the phone. Choose Ability creation or Skill creation.
Discuss, review, then use the displayed phone confirm command.
Enter practice ability [name] or practice skill [name] with the approved name.
Practice may need repeating; Voyage decides native offers and learning.
Approval does not grant an ability or skill.
