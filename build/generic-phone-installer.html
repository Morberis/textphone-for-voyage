Modular Phone 0.6.0

Prepare a complete world export with the phone added. This page works locally; it sends no files anywhere and does not change your live world.

1. Choose your original export

Use the complete initial GameState JSON exported from Voyage Studio. Keep that original as your backup. A game save or a partial mod is not a world export.

Existing phone_mod_ records are replaced as one profile. Other triggers and world content are retained. The phone narrator bridge is prepended once.

2. Review and download

Choose a world export to begin.

3. Add it to a test remix

In Voyage Studio, open Content and its JSON editor. Replace the complete initial GameState JSON with the prepared complete export, then save. Read back the saved JSON and create a new test game. Changes to a world definition do not migrate existing saves.

Test phone, phone store, app navigation and your host's ordinary gameplay before using the integration in your main world. The documentation explains configurable apps and model-generated content limits.
